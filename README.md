# BeePulse

Интерактивный лендинг концепта **BeePulse** — системы раннего предупреждения о проблемах в пчелиных ульях.
BeePulse анализирует звук, вибрации, микроклимат и массу улья и подсказывает пчеловоду, когда колонии нужна проверка. Это не диагностическое устройство.

**Сайт:** https://nightmrazz.github.io/beepulse/

## Что на странице
- Интерактивная демо-панель пасеки со сценариями
- 3D-модель улья с компонентами (Three.js): ESP32, MAX9814, MPU6050, BME280, Load Cell + HX711
- Моушн-дизайн на Motion

## Запуск
Один файл `index.html` — откройте в браузере, сборка не нужна.
